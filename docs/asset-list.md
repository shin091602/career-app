# 素材リスト

画像・動画は**素材ID**で参照する。実ファイルは `public/assets/<プロトタイプ名>/<素材ID>.<拡張子>` に置く。
ファイルが無い間は、色付きの矩形に素材IDを表示するダミーが出る（実装はダミーのまま進めてよい）。

## ルール

- 新しい素材が必要になったら、**実装より先にこの表へ1行追加する**
- 推奨サイズ
  - 背景：9:16（縦長）。目安 1080×1920 px
  - 人物：透過PNG。目安 800×1400 px。中央下寄せで配置される
- 素材は開発者が手作業で生成する。エージェントは表への追記までを行う
- 実在の企業名・ロゴ・実在人物を思わせるものは使わない
