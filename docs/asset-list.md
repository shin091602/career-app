# 素材リスト（課題型プロトタイプ用）

> ショートドラマ型（`novel-bank` / `novel-ad`）の素材は、このファイルではなく
> **`docs/shotlist/<エピソードID>.md`** で管理しています。
> 脚本と制作メモから `npm run shotlist` で生成されるので、直接編集しないでください。

画像は**素材ID**で参照する。実ファイルは `public/assets/<プロトタイプ名>/<素材ID>.<拡張子>` に置く。
ファイルが無い間はダミー表示になる（実装はダミーのまま進めてよい）。

## ルール

- 新しい素材が必要になったら、**実装より先にこの表へ1行追加する**
- 推奨サイズ
  - 背景：9:16（縦長）。目安 1080×1920 px
  - 書類：4:3。目安 1200×900 px
- 素材は開発者が手作業で生成する。エージェントは表への追記までを行う
- 実在の企業名・ロゴ・実在人物を思わせるものは使わない

## task-bank（銀行員・課題）

課題画面では画像を使っていない。必要になったらここに追記する。
