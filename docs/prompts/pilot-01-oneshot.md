# 他のAIに pilot-01 の3ショットを作らせるプロンプト（ワンショット）

`pilot-01` と同じ3ショットを、別のツール（ChatGPT の Astra など）に
**1回の指示で**作らせて品質を比べるためのプロンプト。

- 下の `---` の中をそのままコピーして渡す
- 返ってきた動画は `p1.mp4` / `p2.mp4` / `p3.mp4` の名前で `inbox/` に置く
  （`media/handmade/pilot-01.json` で別名にも対応できる）
- 比較ページ：`npm run media -- review --episode pilot-01 --serve`

---

縦型ショートドラマの素材を3ショット、動画で作ってください。日本の中高生向けに「銀行員の仕事」を体験させるアプリで使います。字幕はアプリ側で重ねるので、映像に文字は入れないでください。

## 全ショット共通の条件

- **実写**（写真と見分けがつかない質感。自然光、肌や布の質感が分かる解像感、浅い被写界深度）。イラスト・アニメ調・CG・3Dレンダリングにしない
- **縦9:16。720×1280 以上**。MP4（H.264）、1本あたり数MB以内
- **一人称視点。カメラ＝新人銀行員の目線で、主人公は画面に映さない**（相手の顔・手元・机で見せる）。カメラの高さは椅子に座った目線
- **音声を動画に入れる**。セリフは**日本語**で、口の動きと合わせる。ナレーションや効果音の追加は不要
- **画面に文字・字幕・ロゴ・透かしを入れない**
- 実在の企業名・ロゴ・実在人物を思わせるものを出さない（登場人物・会社はすべて架空）
- 場所は**地方銀行の支店の応接室のみ**（低いテーブル、布張りのソファ、壁際のパーテーション、奥に窓口のフロア）。3ショットとも同じ部屋に見えること

## 登場人物（3ショットで同じ人物に見えること）

- **融資課長**：40代後半の日本人男性。がっしりした体格、七三に分けた黒髪、銀縁の眼鏡、無精ひげはなし。濃紺のスーツに濃紺のネクタイ。感情を出さない
- **町工場の社長**：60代半ばの日本人男性。白髪の短髪、日に焼けた顔、太い指。ベージュの作業着に濃紺のインナー

**先に各人物の設定画（無地の薄いグレー背景・正面・上半身）を1枚ずつ作り、それを参照しながら3ショットを作ってください。**人物の顔・髪型・ひげの有無・服装をショット間で変えないでください。

## ショット

### p1（6秒）融資課長

椅子に座っている「私」の前に課長が歩いてきて、手に持ったファイルを低いテーブルに置き、こちらを見下ろして言う。革靴の足音と、紙の束が机に当たる音。

> 「新人、この融資は君が判断しろ。明日の朝までだ。」

### p2（8秒）町工場の社長

テーブルを挟んで正面に座った社長が、膝に手を置いて深く頭を下げている。数秒そのまま静止し、ゆっくり顔を上げてこちらを正面から見る。頭と肩が画面の大きな部分を占める近さ。言い終わったあとは動きを止める（ここでアプリ側の選択肢が出るため）。

> 「どうか……この工場を守りたいんです。」

### p3（6秒）融資課長

テーブルを挟んで正面のソファに座った課長が、目を細めてわずかに身を乗り出し、問い詰めるように言う。バストショットで顔が画面の上半分を占める。静かな室内で、空調の低い音だけ。

> 「根拠は？　数字で説明できるか。」

## 納品

- `p1.mp4` / `p2.mp4` / `p3.mp4` の3ファイル（縦9:16・音声込み）
- 人物の設定画も一緒に（差し替えや追加ショットに使うため）
