## 進め方

上から順に、プロンプトを1つずつ Flow に貼って作っていく。

1. **人物の設定画**を3方向ずつ作り、Flow の Ingredients に登録する（2枚目以降は1枚目を参照画像に）
2. **場所**の背景画を作る
3. **キーフレーム**を作る。人物の設定画と場所を参照画像に入れる
4. **クリップ**を作る。Frames to Video で「始点」「終点」のキーフレームを指定し、プロンプトを貼る
   （終点が「なし」のものは始点だけ。尺は8秒でも10秒でもよい。アプリが実際の長さに合わせる）
5. **保存名どおりの名前**で `inbox/` に置き、`npm run import-assets` を実行する
   （キーフレームも入れると、動画が無いときの代替表示に使われる。設定画と場所は Flow の中で使うだけでよい）

同じ人物は、どのキーフレームでも**同じ設定画**を参照させること。顔が揃う一番の決め手になる。
